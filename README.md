# report-card

A single-file, printable student report card template: `report-card.html`.

- Open `report-card.html` in any modern browser. There is nothing to install and it makes no network request.
- Click any field on the card to edit it in place, including the institution name, student details, subjects, marks and remarks.
- Row grades, totals, percentage and overall grade recalculate as you type. Marks that are not a number, or above the row maximum, are flagged and left out of the totals.
- Use the Print button and choose Save as PDF for a one page A4 copy. Enable background graphics in the print dialog to keep the shading.

Copy the file per student, or per term, and rename it freely: nothing is referenced by relative path.
